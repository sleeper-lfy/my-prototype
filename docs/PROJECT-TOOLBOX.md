# 项目工具箱（v0.3.0）

UI 工作区上方和地图工具栏均有“项目工具箱 / Project toolbox”。所有编辑在本机运行，不使用收费 API。工具箱修改活动文档后，关闭时刷新编辑器，使内存状态与磁盘一致。

## 项目和完整备份

在“项目与完整备份”中新建项目、添加 UI 页面或地图、切换已有文档。当前活动 UI 和地图继续兼容旧版 `project.json`、`map.json`，其他页面、地图和模板保存在 `workbench.json`。升级会识别旧版活动文档。

完整项目 ZIP 包含项目内所有页面、地图、评论、模板、原始图片和字体。导入创建新项目，原有项目保留；素材校验 SHA-256 后恢复到本机资源目录。普通 JSON 导出仍只包含配置，跨电脑迁移请选择完整 ZIP。单个完整 ZIP 最大 50 MiB，解压总量最大 256 MiB，单个条目最大 30 MiB。

## 地图块与组件模板

UI 先多选组件，地图先框选区域，再打开工具箱保存模板。地图也可以填写 X/Y 和格宽/深；必须包含完整物件占地。保存的地图块保留各图层、地砖、独立物件、阻挡和标记，并出现在地图素材区，可整体拖入地图。

模板可以在指定 X/Y 放置关联实例。地图布局支持 90/180/270 度旋转和镜像，改变格子布局、占地和锚点位置。可以配置物件的 0/90/180/270 度及镜像方向对应素材，新保存的地图块会按方向切换美术；未配置时保持原图，需要自行补齐对应素材，工具不会生成新的美术方向。

选区可更新主模板；先预览实例更新，再执行应用。实例更新同步外观、资源引用、尺寸和物件占地，保留本地字段覆盖、锁定组件、稳定 ID、位置及关联评论。更新不添加/删除或重新组织组件结构；结构变化应保存成新模板。图层锁定和占地越界会阻止不合法更新。

## 瓦片图集、连接与放置规则

先通过地图素材导入原始图片，在“瓦片图集”指定单元像素宽高、外边距和间距。切分会创建独立裁切瓦片，原始图片字节不变。它支持规则矩形图集，不会自动推断任意美术拼图的边界。

在“连接与放置规则”中配置道路、河流或围墙：北=1、东=2、南=4、西=8，邻接掩码组合决定端点、直线、转角和交叉贴图。至少配置默认 0。保存后在画布使用“连接画笔”，拖动形成连续路径，并重算邻近连接。贴图规则由用户提供，不根据图片内容猜测连接关系。

物件可指定允许的地形和是否禁止同图层占地重叠。放置及移动使用整块占地进行验证；参考地形为该格最前面的地形瓦片。桥梁可允许水面，房屋可限制为草地或石砖。

## UI 交互、分辨率和文案

“交互与文案”支持点击组件打开、关闭、切换目标可见性、切换页面或更新文字。配置后到“UI 交互预览”实际点击。预览不改变工作设计，游戏业务脚本仍由 Godot 项目维护。

预览支持多种窗口分辨率、安全区、正常/悬停/按下/禁用贴图，以及游戏文案语言。窗口尺寸变化采用原设计坐标，便于发现裁切和空白，不会凭空生成响应式布局规则。

文案翻译按组件 ID 和语言代码保存，与编辑器本身中英切换分开。真实文字宽度检查使用浏览器字体测量；疑似缺字检查比较字体渲染结果，字体回退、复杂文字和最终排版仍需目视检查。

## 九宫格、测量和检查

九宫格边界可直接拖动，也可输入像素边距，并即时查看拉伸效果。按钮可分别设置正常、悬停、按下和禁用贴图，在交互预览中查看。

地图“测量”工具点选两格显示格距离；工具箱同时报告格距离、同地形在 X/Y 方向的连续宽度、可通过宽度和可行走路径长度。参考图使用已导入素材，配置像素位置、尺寸、透明度，作为锁定的编辑覆盖层显示，不会当成游戏物件导出。

项目检查遍历当前项目所有页面和地图，报告资源缺失、组件越界、疑似文字溢出、出生点阻挡及不可到达的出口。文字估算应在 UI 预览中复核；检查通过不代替美术验收。

## Godot 增量更新

工具箱可选择现有 Godot 项目文件夹，按实际文件 SHA-256 显示新增、删除、未变和冲突。下载的更新 ZIP 包含完整生成文件、清单和独立 `sync.mjs`，无需 npm 依赖。

```text
node sync.mjs --project "C:\Games\MyGame"
node sync.mjs --project "C:\Games\MyGame" --apply
```

第一次使用时先创建目标目录。Windows 安装版可以用应用内置 `node.exe`。只管理 `studio_generated/`；用户脚本、外部业务场景和已有 `project.godot` 保留。建议在自己维护的场景中实例化生成的 UI/地图。

手工改过的生成文件会成为冲突，默认拒绝更新。审阅后可逐个接受精确路径：

```text
node sync.mjs --project "C:\Games\MyGame" --apply --accept studio_generated/ui/ashfall/main.tscn
```

旧文件备份到 `.studio-backups/`，更新清单在 `.studio-sync.json`。业务脚本应放在生成目录之外；如果修改生成场景本身，必须处理冲突，不能假定自动合并场景文本。导出目标为 Godot 4.3+，真实运行与截图结果见本版验证记录。
