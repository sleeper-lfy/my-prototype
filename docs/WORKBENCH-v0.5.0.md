# v0.5.0 游戏内容验证工作流

本版围绕角色动作、地图可玩性、资源质量与 Codex 任务验收扩展本地工作流。编辑、保存、反馈包与补丁仍可离线使用；工具不会自动调用付费 AI 服务。

## 角色试演、时间轴与装备

进入顶部的 **像素动画 / Pixel animation**，使用新增工作台试演当前角色。人物主体参考仍为 **64×96**；攻击、装备和肢体可以超出主体，渲染与导出保留扩展范围及固定原点。

事件时间轴用于安排判定、音效、特效和位移等时间点。事件包含名称及数据，导出时保留到 Godot 事件表。音效和特效事件提供触发信息，实际游戏资源与逻辑需要在 Godot 中接入。

装备按挂点和层级显示，配色和设置随动画 JSON 保存。使用多动作预览检查握持位置和穿插。骨骼自动计算与程序像素样例用于功能验证，美术效果需要单独验收。

## 地图可玩性

进入 **2.5D 地图 / 2.5D map**，配置角色碰撞占地，放置出生点、出口和交互点，再运行可达性检查及走动预览。检查结果依据当前二维格网和阻挡规则，不代表三维物理或高低地形导航。

建筑图片、整数格占地、碰撞区域和遮挡排序可以分别表达。树冠与屋檐可以覆盖更大的图片范围，同时使用较小的树干或墙体碰撞范围。修改后观察路径及人物前后关系，再导出 Godot 场景。

## Godot UI 回读

导入现有 `.tscn` 文本进行有限 UI 回读，先查看支持范围、属性差异与警告，再决定是否应用。导入器不运行场景脚本。可编辑范围以导入报告为准，不支持的节点和属性不会伪装为完整可编辑内容。

原始 Godot 工程保持独立；导出的 UI 使用生成目录。复杂自定义节点、脚本逻辑、主题继承、动画轨道或实例覆盖需在 Godot 中维护。

## 美术资源体检

资源面板提供跨 UI、地图、模板和动画的引用查询。选择资源后运行检查，查看像素缩放、透明像素、调色板、瓦片边缘与格单位相关提示。图像类检查基于实际解码像素；透明边缘、颜色与接缝属于启发式提示，需要结合素材用途判断。

替换前先预览受影响的引用，确认后保持组件及素材 ID。来源和许可证信息可以随资源保存。历史项目中的同名资源不会因当前文档替换而被静默批量覆盖。

## Codex 任务队列

从待处理意见建立独立任务并导出反馈 ZIP。将任务交给 Codex 时，要求其读取包内说明与配套 skill，只返回允许范围内的增量补丁。返回后查看改动数量、字段差异和自动检查，确认应用后再进行人工验收。

自动检查负责结构、资源引用、尺寸和动作范围；人工验收负责视觉效果、动作节奏与设计意图。待验收状态不等于已通过。

## 保存与安装

升级保留原有项目数据。UI、地图和项目库沿用现有本地存储；动画设置随动画 JSON 保存。完整备份可停止应用后复制 `%LOCALAPPDATA%\GameUIStudio\data`。安装包中的 Logo 使用原始 PNG 及其多尺寸 ICO，未重新生成美术。

实际测试结果见 [v0.5.0 验证记录](VALIDATION-v0.5.0.md)。
