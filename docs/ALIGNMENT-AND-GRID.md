# 吸附、对齐与格单位摆放

UI 设计工作区的画布工具栏提供“吸附”和“辅助线”开关。拖动组件时，靠近其他组件或画布的边缘、中心会吸附并显示对齐线；吸附距离随缩放保持相同屏幕像素范围。松开鼠标后辅助线消失，不会作为组件保存或导出。

按 Shift/Ctrl 多选组件可以整体拖动；使用对齐选项完成左、居中、右、顶部、垂直居中、底部对齐，三个以上组件还可等距分布。锁定组件和由 Container 自动定位的子组件不参与自由位置调整。父子同时选中时，子组件只随父组件移动一次。

地图使用整数格坐标和整数占地。默认一格为 64×32 像素的等距菱形；素材图片可以高出一格，其视觉高度与碰撞占地分开。树木可占 1×1 格，房屋可占 2×2 或更大区域。

从素材面板拖入地图时，轮廓显示全部占地格子和落点。地砖按单格铺设，多格地形范围重复所选地砖；建筑等物件保留独立图片与稳定 ID。完整占地必须位于地图内，锁定图层不能接收摆放。

图层列表按从后到前排列，可调整顺序。每层先显示地形，再按脚底深度显示同层物件；走动测试角色使用所选角色层。物件可在属性中换层，ID 和关联评论保持不变。Godot 导出使用真实 TileMapLayer、对应物件层级及同样的占地碰撞。
