# Map v1 contract

Document: `{schemaVersion:1,kind:'studio-map',id,name,revision,grid:{width,height,tileWidth,tileHeight},actorLayerId?,assets,layers,objects,blocked,markers,reviews,history}`. Width/height integer 1..128. `tileWidth`/`tileHeight` 8..256. `assets`: `{id,name,src,kind:'tile'|'object',width,height,footprint?:{width,height},atlas?:{x,y,width,height}}`, local /assets/ or /local-assets/. Atlas rectangle selects pixels of source image; width/height are display dimensions independent of occupied cells. Asset footprint is integer 1..128 in each axis, default 1×1 for older files. Object asset footprint initializes collision occupancy; tile asset footprint is a rectangular repeat stamp of single-cell tiles. Library assets may be larger than the current map, but placement rejects a footprint that cannot fully fit, before any mutation. `layers`: `{id,name,visible,locked,cells:{'x,y':assetId}}`, ordered back to front. `objects`: `{id,name,assetId,layerId,x,y,width,height,anchorX,anchorY,blocking,footprint:{width,height}}`, integer grid coordinates, pixel display size, anchors 0..1, footprint extends from x,y in positive grid axes. Layer array order is back to front. For each layer, render its terrain followed by its objects sorted by `(x+y)` (foot position, stable source order on ties). The next layer can cover prior layers' terrain and objects. Use shared `getMapRenderLayers(map)` => `{layer,index,terrainZ:index*2,objectZ:index*2+1,objects,actor}` bands in editor and Godot. Optional `actorLayerId` names an existing layer; `getActorLayerId(map)` defaults older documents to `decoration` if present, otherwise the last layer. The character joins that layer's object Y-sort band. Hidden layers hide the character in that band as well as artwork, while collision remains active. `blocked`: unique `'x,y'` strings. `markers`: `{id,type:'spawn'|'exit'|'trigger',x,y,name}`. A marker occupies one cell; first spawn seeds preview character. Hidden layers do not draw but retain collision; locked layers block AI edits and normal editor tools.

Reviews: `{id,target:{type:'object',objectId} | {type:'region',layerId,x,y,width,height},targetText,expected,protectedProperties:[],priority:'low'|'medium'|'high'|'critical',status:'pending'|'modified'|'review'|'approved',createdAt}`. Object protections: `x,y,width,height,anchorX,anchorY,assetId,name,blocking,footprint,footprint.width,footprint.height,id,layerId`. Region protections: `cells,blocked`. Region changes can paint/erase tiles or alter walkability in that region only. Other unresolved reviews also protect overlapping fields/regions.

Patch: `{schemaVersion:1,kind:'studio-map-patch',projectId,baseRevision,summary,reviewIds,changes:[{type:'object',objectId,set:{x:4}} | {type:'cell',layerId,x,y,assetId:string|null} | {type:'blocked',x,y,value:boolean}]}`. POST apply optionally includes `selectedIndices`; selecting a subset leaves review status pending, while complete patch marks selected reviews modified. Duplicate target fields/cells rejected. All validation atomic. IDs/types/layer membership cannot be patched. Latest-only optimistic rollback checks each touched field/cell for conflicts, preserves unrelated changes, and records history.

Pure exports in src/mapModel.js: `validateMap(map)`, `createVillageMap()`, `isoToScreen(x,y,grid)` => `{x,y}`, `screenToIso(x,y,grid)` => floating `{x,y}`, `isWalkable(map,x,y)`, `findPath(map,start,end)` => cell array inclusive endpoints or [], `applyMapPatch(map,patch,{selectedIndices}={})`, `previewMapPatch(map,patch,{selectedIndices}={})` => `{project,changes}`, `rollbackMapPatch(map,historyId)`, `buildMapFeedback(map)`.

Routes, registered by async `mountMapRoutes(app,{dataDir,mutate,archive,readAsset,resolveAssetPath,createMapGodotFiles})`: GET /api/map => project; PUT /api/map `{project,baseRevision}` => saved project with incremented revision; POST /api/map/import `{project}` => imported project; POST /api/map/patch/preview `{patch,selectedIndices?}` => `{project,changes}`; POST /api/map/patch `{patch,selectedIndices?}` => saved project; POST /api/map/rollback `{historyId}` => project; POST /api/map/feedback `{baseRevision,screenshots:{[reviewId]:dataUrl}}` => archive metadata; POST /api/map/godot => archive metadata. Exporter returns `{files:{[path]:string},assets:[{src,destination}]}` and receives map.

Map UI and UI design have independent persistence and revision streams. Feedback packages include only pending reviews, local crops, relevant objects/cells/assets, rules, patch template; full map JSON exported separately for complete dry-run. Importing JSON does not embed asset files.


Palette placement helpers: `getAssetFootprint(asset)` returns `{width,height}` with a 1×1 default. `planMapPlacement(map,{assetId,layerId,x,y,footprint?})` validates the current map, target layer lock, integer coordinates and complete footprint bounds before returning either `{type:'tile',layerId,x,y,footprint,cells:[{x,y,assetId}]}` or `{type:'object',object}`. The object receives a fresh stable ID, source display dimensions, anchor 0.5/1 and blocking=true. No mutation or revision increment occurs. Tile stamps replace underlying cells; deliberate object overlap is permitted. `moveMapObject(map,{objectId,layerId?,x?,y?,footprint?})` returns a validated clone, preserving stable IDs, comments, display pixels and revision; both source and destination layers must be unlocked. The editor performs one normal save for the accepted placement/move.
