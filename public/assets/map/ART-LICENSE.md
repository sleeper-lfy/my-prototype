# Village sample artwork

Original SVG artwork created for Game UI Studio, 2026. Licensed under the repository's MIT license. These files contain no external resources, scripts, embedded raster images or third-party artwork.

Tiles use a 64 × 32 diamond, with the tile center at (32,16). Object images use a bottom-center foot anchor `(0.5, 1)`; footprints and collision are stored independently in map documents. Grass, path, water and stone are separate paintable tile materials. Tree, house, wall and chest are editable object sprites.

This is a coherent functional sample for editor/export verification. Art approval is independent from functional or Godot export tests.
